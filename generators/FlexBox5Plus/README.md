# FlexBox5Plus

Box with living hinge and round corners, plus turning latch, inner reinforcements and an unfolding jig (local variant).

Local variant: **not** on the public Boxes.py site, generated by `flexbox5plus.py` of the [tfabien/boxes.py](https://github.com/tfabien/boxes.py) fork through the local server (`companion/`).

| | |
|---|---|
| Home page section | Boxes with a flexible hinge |
| Sliders | Explode, Unfold, Opening |
| Parameters | 42 in the form, 21 influence the 3D model (the others are greyed out) |
| Message translations | none yet (English) |

## Files

| File | Content |
|---|---|
| `generator.json` | 3D descriptor (hand written): display `order`, home page `section`, `local` (class run by the local server), `used` (parameters that influence the 3D model), `notes` (limitations shown under the parameter list) |
| `viz.js` | 3D model: defines `BUILD.FlexBox5Plus`, the JavaScript port of the generator's `render()` (panels, openers, flexible wall) |
| `schema.json` / `texts.json` | parameter form: English structure and per-language labels, **extracted** by `tools/extract_schemas.py` (do not edit) |
| `i18n/<lang>.json` | translations of the messages (`warn` / `fail` / `notes`) of this generator |

## Limitations

- Local variant (not on the Boxes.py site): Generate calls the local server (start_server.bat). Latch pivot vertically centred.
